# EcoMuriaé

Site estático de educação ambiental, com página inicial, quiz, minigame e comparador.

## Publicar no GitHub Pages

1. Envie os arquivos deste projeto para a raiz de um repositório GitHub.
2. No repositório, acesse **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch principal e a pasta **/(root)**, depois salve.
5. Aguarde a publicação e acesse a URL informada pelo GitHub Pages.

O projeto não precisa de etapa de build. Os caminhos internos são relativos, então funcionam tanto em um site de usuário quanto em um site de projeto no GitHub Pages.

O comparador depende de bibliotecas e dados servidos por CDNs externos, portanto precisa de conexão com a internet.
